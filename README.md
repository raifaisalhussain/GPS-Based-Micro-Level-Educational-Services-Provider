# GPS-Based Micro-Level Educational Services Provider (TASKILL)

**BSc Computer Science — Final Year Project (2021)**

**University of Engineering and Technology (UET), Lahore, Pakistan**

TASKILL is a GPS-based educational services platform developed to connect students with nearby tutors. The project aims to make educational support more accessible through location-based tutor discovery, personalised learning opportunities and short-term tutoring services.

## Project Overview

Finding suitable tutors can be challenging due to geographical limitations, availability, cost and communication barriers. TASKILL was designed to address these challenges through a web-based platform where students and tutors can register, create profiles and connect based on their educational requirements and location.

The project was completed as a four-member undergraduate final-year project under academic supervision.

## Key Features

- **Location-Based Tutor Discovery:** Helps students identify tutors in nearby areas using GPS-based concepts.
- **Student and Tutor Registration:** Separate account registration and profile management.
- **Tutor Profiles:** Educational qualifications, expertise, teaching subjects, languages and hourly rates.
- **Course Management:** Tutors can create and manage course information.
- **Student Dashboard:** Students can browse courses, manage profiles and explore tutoring opportunities.
- **Communication Features:** Interfaces supporting tutor-student interactions.
- **Responsive Interface:** Web pages designed for different screen sizes.

## Project Structure

The repository is organised into two main application folders:

- **backend/** — Django project configuration, student and tutor applications, REST API endpoints, database models and migrations.
- **first-app/** — React frontend, reusable components, registration forms, dashboards and supporting assets.

The frontend communicates with the Django backend through REST APIs.

## Research Methodology

The project followed a structured software engineering and research process:

1. **Problem Identification:** Investigated challenges in locating affordable and accessible educational services.
2. **Literature Review:** Reviewed existing platforms, including Indeed, Zippia, TutorMe and Tootar, to identify relevant features and limitations.
3. **Requirements Analysis:** Defined functional and non-functional requirements for students and tutors.
4. **System Design:** Prepared data flow diagrams, use-case diagrams and application workflows.
5. **Implementation:** Developed the React frontend and Django REST API backend.
6. **Functional Evaluation:** Documented test scenarios for registration, login, course management and tutor-student interactions.
